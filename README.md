# AikoMemo

La mémoire de ton Mac. AikoMemo retient, en local, ce qui se passe sur ton ordinateur pour que tu puisses tout retrouver en écrivant comme tu parles :

- « le pdf que j'ai téléchargé depuis Gmail hier »
- « le lien copié avant d'ouvrir Figma »
- « la vidéo reçue par AirDrop la semaine dernière »
- « ce que j'ai copié il y a 2 heures »

## Ce qu'il retient

- **Applis utilisées** : laquelle, quand, combien de temps ;
- **Presse-papiers** : textes, liens, images, fichiers copiés — jamais les mots de passe (gestionnaires de mots de passe ignorés, textes qui ressemblent à un mot de passe ignorés) ;
- **Téléchargements** avec leur origine (Gmail, WhatsApp, AirDrop, WeTransfer, Google Drive…) ;
- **Fichiers** créés, modifiés et ouverts dans les dossiers choisis (Bureau, Documents, Téléchargements par défaut).

Tout reste sur ton Mac (`~/Library/Application Support/AikoMemo`). Pause, applis exclues, durée de mémoire (7 jours à 1 an) et « Tout effacer » sont dans les réglages.

## Utilisation

- **⌃ ⌥ M** ouvre la recherche (raccourci modifiable).
- ↑ ↓ pour choisir, ↩ pour ouvrir (ou recopier), ⌘ ↩ pour afficher dans le Finder, ⌘ C pour copier.

## Installation (Mac)

Télécharge `AikoMemo-Mac.zip` dans les versions, ou compile toi-même : double-clic sur `macos/Installer AikoMemo.command` (outils de développement Apple requis).
